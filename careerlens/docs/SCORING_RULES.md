# Explainable Scoring Principles

This document is a starting point for discussion, not a validated hiring instrument.

1. **Separate proficiency from evidence coverage.** A student may have a skill that is not yet documented.
2. **Never convert missing evidence into a zero skill score.** Mark it as unknown / not observed.
3. **Use a published rubric per target role.** Define the required skills, expected levels, and weights before scoring.
4. **Show component scores and evidence.** Every result should explain what contributed and what evidence is missing.
5. **Use deterministic calculations for the score.** An LLM may summarize evidence and propose next steps, but should not invent numeric scores.
6. **Include recency and provenance.** Show source and date where available.
7. **Avoid false precision.** A readiness score is a guidance signal, not a guarantee of placement or hiring success.
8. **Validate before making claims.** Demo values must be labeled as illustrative; calibrate rubrics using consented, representative data before real use.
